Early access install guide

Install Rooted Memories

You’ve been invited to join a private family tree. Download the app below, then log in using the phone number that received your invitation.

Download the app

Choose the version that matches your device.

Install on iPhone Uses Apple TestFlight during early access Install on Android Install manually during early access

iPhone steps

  1. Tap Install on iPhone above.
  2. Install TestFlight if prompted.
  3. Open the Rooted Memories TestFlight page.
  4. Tap Install.
  5. Open Rooted Memories.
  6. Tap Log In.
  7. Enter the phone number that received the invitation.
  8. Enter the verification code.
  9. Your invited family tree should open.

Android steps

  1. Tap Download on Android above.
  2. Download Rooted Memories from Google Play.
  3. Open Rooted Memories.
  4. Tap Log In.
  5. Enter the phone number that received the invitation.
  6. Enter the verification code.
  7. Your invited family tree should open.

Use the invited phone number

You must log in with the same phone number that received the invitation. If you use a different number, the app may not connect you to the correct family tree.

If +44 is already selected, enter your UK number without the first 0.

Use: 7 555 555 555

Not: 07 555 555 555

Not: +44 7 555 555 555

Having trouble?

  • Make sure you are using the phone number that received the invite.
  • Check that the phone number has been entered correctly.

If you still cannot access the tree, contact the person who invited you.

Ready to join your family tree?

Download the app, tap Log In, and use the phone number that received your invitation.
