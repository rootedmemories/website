Rooted Memories Install App
Early access invitation

You've been invited to a private family tree.

Install Rooted Memories below, then tap Log In and use the same phone number that received your invitation. Once verified, your invited family tree should open automatically.

Important: do not create a separate account using another phone number. Your invitation is connected to the number the family member used when they invited you.

Step one

Install Rooted Memories on your phone.

Choose your device below. iPhone early access currently uses Apple's TestFlight service. Android installs directly through Google Play.

iPhone Install Rooted Memories Via Apple TestFlight Android Install Rooted Memories Via Google Play
Step two

Open the app and log in.

iPhone

  1. Tap Install Rooted Memories above.
  2. Install TestFlight if Apple asks you to.
  3. Open the Rooted Memories page in TestFlight and tap Install.
  4. Open Rooted Memories.
  5. Tap Log In.
  6. Enter the phone number that received your family invitation.
  7. Enter the verification code sent to your phone.
  8. Your invited family tree should open.

Android

  1. Tap Install Rooted Memories above.
  2. Install the app through Google Play.
  3. Open Rooted Memories.
  4. Tap Log In.
  5. Enter the phone number that received your family invitation.
  6. Enter the verification code sent to your phone.
  7. Your invited family tree should open.
Important

Use exactly the same phone number that received the invitation.

Your family invitation is attached to that phone number. If you log in using a different number, Rooted Memories may not know which private family tree you were invited to.

Use 7 555 555 555
Not 07 555 555 555
Not +44 7 555 555 555

This example applies when +44 is already selected in the app. In that case, leave out the first 0 from a UK mobile number.

If your family tree does not appear.

Check the phone number

Make sure it is the same number that received the original invitation.

Check the country code

If a country code is already selected, do not type the country code into the number field again.

Contact the person who invited you

If the number is correct and the tree still does not appear, ask the family member who sent the invitation to confirm which number they used.

Ready to join your family tree?

Install the app, tap Log In and use the phone number connected to your invitation.
