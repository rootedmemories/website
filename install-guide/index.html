Early access install guide

How to install Rooted Memories

You’ve been invited to join a private family tree. Follow the steps below to install the app and access the tree you were invited to.

Important: tap Log In, not Get Started

If you have been invited to an existing family tree, you need to tap Log In on the welcome screen.

Do not tap Get Started, as that is for creating a new tree.

For iPhone

  1. Tap the invite link you were sent.
  2. Install TestFlight if prompted.
  3. Open the Rooted Memories TestFlight page.
  4. Tap Install.
  5. Open Rooted Memories.
  6. Tap Log In.
  7. Enter the same phone number the invite was sent to.
  8. Enter the verification code.
  9. You should then be taken into the family tree.

For Android

  1. Tap the download link you were sent.
  2. Download the APK file.
  3. Your phone may ask you to allow installs from this source.
  4. Tap Allow or Settings, then enable installation.
  5. Return to the file and tap Install.
  6. Open Rooted Memories.
  7. Tap Log In.
  8. Enter the same phone number the invite was sent to.
  9. Enter the verification code.
  10. You should then be taken into the family tree.

Use the invited phone number

Only use the phone number that received the invitation. If you use a different number, the app may not connect you to the correct family tree.

For UK numbers, if +44 is already selected, enter the number without the first 0.

Example: use 7911000001, not 07911000001 or +447911000001.

Need help getting in?

If your invite does not work, check that you are using the correct phone number and that you tapped Log In rather than Get Started.
