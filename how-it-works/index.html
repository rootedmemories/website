Getting set up

Four steps.
A clear starting point.

A Tree is the shared space for your family. A Leaf is a record for an individual person, whether or not they have an account.

01 / Set up the Tree 02 / Upload a photograph 03 / Link the people pictured 04 / Invite relatives
  1. 01

    Set up the Tree

    Create a Tree, add the people you want to include as Leaves and record how they are related. Someone can have a Leaf without signing up themselves.

  2. 02

    Upload a photograph

    Add a photograph and give it a caption. Record the occasion, the location or a detail that would otherwise be hard to recognise.

    For example: “Mum's 60th birthday, Brighton, June 2018.”

  3. 03

    Link the people pictured

    Associate the photograph with the relevant Leaves. If several relatives appear in it, the same upload can be linked to each of them within that Tree.

  4. 04

    Invite relatives to join

    Invite relatives to the Tree so they can sign in and add their own uploads. A Leaf records a person; an invitation gives someone access to participate.

Before you begin

A few useful distinctions.

Does everyone in the Tree need an account?

No. A Leaf can represent someone who has not registered. An account is needed for someone to sign in and participate.

Will removing a photograph from one Leaf delete it everywhere?

Removing one association leaves the photograph available on other Leaves it is still linked to within that Tree. If no Leaf associations remain, the photograph is permanently removed from the Tree.

What happens to someone's uploads if they leave?

When a member leaves or is removed from a Tree, their uploads in that Tree are permanently removed, including photographs linked to other Leaves. Read the content and removal terms before changing membership.
